# Skin Maker

PEK's official, bundled plugin for making skins in the Flutter app.

- Open it from Settings > Appearance > **Make a skin**, or Plugins > Skin Maker.
- Start from any skin, from one accent colour or hue, or from a pasted `skin.json`.
- Set the accent, background, cards, text and corner size; the other colours follow (or set each by hand under *More colours*).
- Text that would be hard to read is refused. Save, save and use, or copy the `skin.json` (installs in the web build too).

Permissions: `skins` (reserved for this plugin). No network, no storage. Built in: it cannot be removed and it updates from the PEK Store Official shelf.
