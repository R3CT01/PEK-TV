Plugin guide

Writing PEK TV plugins

A plugin is a folder with a plugin.json, a Python screen.py that describes its screen (PEK TV draws it with the app's own widgets) and, optionally, a Python backend.py. Plugins are Python only: JavaScript (ui.js) is no longer accepted. Anything that is not bundled with PEK TV runs sandboxed.

Three ways to get a plugin

TierWhat it isMarked as
OfficialPlugins that ship with PEK TV, or that the owner publishes on the PEK Store's Official shelf.Listed above the separator on the Plugins page
PEK StorePlugins other people submitted and the owner approved.Community
GitHubPlugins → Install from GitHub, then owner/repo. PEK TV keeps no list, so there is nothing to submit.Unverified. PEK TV did not review it and the developer is responsible for it

There is a Settings switch (Plugins and skins from GitHub) for GitHub installs and a first-time warning. A build that must not install from GitHub can start with PEK_ALLOW_GITHUB=0. Every tier gets the same sandbox, the same safety scan and the same permissions screen.

plugin.json

{
  "name": "My Plugin",
  "version": "1.0.0",
  "permissions": {
    "network": ["api.example.com", "*.cdn.example.com"],
    "storage": true,
    "library": true
  },
  "ui": { "navTab": "Discover" },
  "flutter": { "screen": "screen.py" }
}

No permission listed means no access. The flutter entry is required (it names the screen file). The optional ui block only changes PEK TV's own screens:

  • navTab adds a menu / More entry that opens the plugin (max 20 characters).
  • warning shows a screen before the permissions screen. Plain text only: a title (max 60), up to 5 paragraphs of 400 characters, and a button label (max 40). Shortcuts: "warning": "one paragraph" or an array of paragraphs.

Permissions

PermissionWhat it allows
networkList of https host names (no IPs, no localhost). *.x.com matches subdomains. Poster art, provider logos and the YouTube trailer player (www.youtube-nocookie.com) only load from listed hosts.
storageA small private key/value store (256 KB) and read access to plugins/<id>/data/.
libraryLets the Python backend call pek_host.library_titles(): titles and years only, never file names or folders.
torrentui.play_torrent(...): start a stream in PEK TV's player. The plugin never sees the provider address or key.
favoritesui.favorite_add / ui.favorite_remove: the shared Favorites.
providersui.provider_button: a “Watch on <service>” button that opens the service's app.
pluginsui.streamers / ui.open_plugin: hand a title to another plugin that can stream it.
watchedui.is_watched / ui.set_watched (and the _many versions): check or set movies and episodes in PEK TV's Watch History. The plugin only learns about the items it asks for.
skinsReserved for the official skin-maker plugin. Any other plugin that asks for it is refused.

The screen API (screen.py)

A screen describes the UI as data and PEK TV draws it. The screen runs under the same guard as backend.py (same allowed imports, plus pek_ui) and can only ask for a short list of things; it never runs code in the app. Import pek_host as h for network and storage and pek_ui as ui for the building blocks.

CallWhat it does
def render()Return the tree to draw. Runs again after taps and after a background job finishes.
def start()Optional. Runs once when the screen first opens.
ui.background(work, done, fail)Run work on another thread (it may wait for the network), then done(result) or fail(message); the screen redraws by itself.
h.fetch_text(url) / h.fetch_json(url)HTTPS GET of an allowed host. Needs network. Call it inside ui.background.
h.write_json / h.read_jsonPrivate store in the plugin's data/ folder. Needs storage.
ui.card / list_row / button / text / heading / column / rowBasic building blocks. Text only, no HTML. ui.button(label, fn, primary=, selected=, autofocus=).
ui.episode_row(title, meta, text, image, dim=, on=)One episode: picture, title, a line of facts and a description.
ui.poster_card(title, sub, poster, on, badge=, year=, kind=)A poster tile like the library grid. Movies get the watched tick automatically.
ui.grid(kids, min_col=, scroll=)Responsive poster grid, or one sideways-scrolling row.
ui.tabs / text_input / spinner / toggleTab strip, text box, loading wheel, on/off switch.
ui.video(video_id, autoplay=, muted=)An inline YouTube trailer pinned to the top of the screen. Needs www.youtube-nocookie.com in network. ui.open_trailer(video_id) opens YouTube instead.
ui.set_back(fn)Make Back call fn first so a plugin can step out of its own screens. Pass None to let Back close the plugin.
ui.scroll_top()Scroll back to the top after changing page.
ui.ctx()Language, region, whether the device is a TV, and the favorites.
ui.toast(message) / ui.close_plugin()Show a message / close the plugin.
import pek_ui as ui

def render():
    return ui.column(
        ui.heading("Hello"),
        ui.button("Tap me", lambda: ui.toast("Hi"), primary=True),
    )

A screen that raises an error or runs too long (6 s to draw, 15 s per tap, 25 s per background job) shows an error card with Try again. See FLUTTER_PLUGINS.md for the full reference.

Backend (backend.py)

Optional. It must pass an automatic scan and then runs with a limited host API. run() is called once at startup with a 10 second limit.

  • Allowed imports: json re math datetime time collections itertools functools string textwrap html urllib.parse base64 hashlib random statistics decimal fractions typing dataclasses enum copy operator unicodedata, your own .py files in the same folder, and pek_host.
  • Not allowed: eval exec compile open getattr setattr __import__, any attribute starting with _, os sys subprocess socket ctypes and similar, and native or compiled files.
  • import pek_host as h gives h.fetch_text(url), h.fetch_json(url), h.write_json(name, obj), h.read_json(name) and h.library_titles() (needs "library": true). Network and storage obey plugin.json. The old name hesper_host also works.
  • Installed plugins' backends start the next time PEK TV starts. If the scan refuses one, the reason is in PEK TV's log ([PEK Plugin Guard] REFUSED ...).
import pek_host as h

def run():
    titles = h.library_titles()
    h.write_json("library.json", {"count": len(titles)})

Packaging and installing

In the app: Plugins → Install from .zip, pick the file, read the permissions and confirm. Hold a plugin's row to remove it. The zip needs plugin.json (with a "flutter" entry) and screen.py (a plugin that only has a ui.js, or any .js file, is refused), at the top or inside one folder (the folder name becomes the plugin id: lowercase letters, digits, - and _). Installing again with the same id updates the plugin and keeps its data/ folder.

  • Allowed files: .json .css .md .txt .png .jpg .jpeg .gif .webp .ico .woff .woff2 .ttf .otf, and .py for the backend.
  • Limits: 200 files, 2 MB per file (200 KB per .py), 8 MB total, no hidden files, no .. in paths.
  • On Android the plugins folder is private to the app, so a .zip install is the way to add plugins. On a computer or Termux you can also drop a folder into plugins/.

Publish on GitHub

  1. Put plugin.json and screen.py at the top of your zip, or inside one folder.
  2. Make a GitHub Release and attach the zip (a .zip asset up to 8 MB). PEK TV installs the latest release.
  3. Keep the folder name or plugin name the same across versions so updates replace the old copy.

More APIs

Torrent streaming

With "torrent": true, a screen can call ui.play_torrent(source, label, season=, episode=, kind=, name=, year=, image=). source is a magnet link or an https .torrent link on a host listed under network. PEK TV shows its own buffering box and opens the player when enough is downloaded, and keeps the position under Resume Watching when you pass kind and name. PEK TV has no torrent search of its own: the plugin supplies the source.

Launching, streaming apps and favorites

def on_launch(intent) runs when PEK TV opens your plugin on a title (from Favorites or another plugin). A plugin that can play a title declares "provides": {"stream": true}. ui.provider_button opens a streaming service's app on a title. Streaming services and their Android packages are listed in tools/providers.json (run node tools/sync_providers.js after changing it).

The full reference is PLUGINS.md in the repository.

Skins are not plugins

A skin changes colours and corner size. It cannot run code, contain CSS or use the network. Install one from Settings → Appearance → Install skin from .zip (or from GitHub). A zip is a plugin or a skin, never both: installing the wrong kind fails with a message that says which it is.

{
  "name": "Sunset",
  "author": "You",
  "version": "1.0.0",
  "description": "Warm dusk colours with soft rounded corners.",
  "tokens": { "bg": "#1a0f14", "text": "#fff1e8", "accent": "#ffb347", "radius": "14px" }
}

Allowed files: json md txt png jpg jpeg gif webp ico woff woff2 ttf otf, up to 60 files, 2 MB each, 6 MB total. The server re-checks every rule. See SKINS.md.
