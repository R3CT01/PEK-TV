Plugin guide

Writing PEK TV plugins

A plugin is a folder with a plugin.json, a ui.js and, optionally, a Python backend.py. Anything that is not bundled with PEK TV runs sandboxed.

Three ways to get a plugin

TierWhat it isMarked as
OfficialPlugins that ship with PEK TV, or that the owner publishes on the PEK Store's Official shelf.Listed above the separator in the Plugins tab
PEK StorePlugins other people submitted and the owner approved.Community
GitHubSettings → Plugins → Install from GitHub, then owner/repo. PEK TV keeps no list, so there is nothing to submit.Unverified. PEK TV did not review it and the developer is responsible for it

There is a Settings switch for GitHub installs and a first-time warning. A build that must not install from GitHub can start with PEK_ALLOW_GITHUB=0. Every tier gets the same sandbox, the same safety scan and the same permissions screen.

plugin.json

{
  "name": "My Plugin",
  "version": "1.0.0",
  "permissions": {
    "network": ["api.example.com", "*.cdn.example.com"],
    "storage": true,
    "library": true
  },
  "ui": { "navTab": "Discover", "reloadOnInstall": true, "closeOnRemove": true }
}

No permission listed means no access. The optional ui block only changes PEK TV's own screens:

  • navTab adds a sidebar / More entry that opens the plugin.
  • reloadOnInstall reloads the app right after installing.
  • closeOnRemove asks the user to close and reopen PEK TV after the plugin is removed.
  • warning shows a screen before the permissions screen. Plain text only: a title (max 60), up to 5 paragraphs of 400 characters, and a button label (max 40). Shortcuts: "warning": "one paragraph" or an array of paragraphs.

Permissions

PermissionWhat it allows
networkList of https host names (no IPs, no localhost). *.x.com matches subdomains. Poster art and the YouTube player only load from listed hosts.
storageA small private key/value store (256 KB) and read access to plugins/<id>/data/.
libraryLets the Python backend call pek_host.library_titles(): titles and years only, never file names or folders.
torrentpek.torrent.info / search / play. The plugin never sees the provider address or key.
favoritespek.favorites.list / add / remove: the shared Favorites tab.
providersui.providerButton: a “Watch on <service>” button.
pluginspek.plugins.streamers / open: hand a title to another plugin that can stream it.
livepek.live.play and live sessions (channel switcher, guide, now / next banner).

Android: the installer also accepts watched and device. The bridge that exposes pek.watched and pek.device to plugin code is not wired into the sandbox yet, so treat both as planned.

The UI API (ui.js)

Your UI runs in a sandboxed iframe with no access to the page, PEK TV's API, cookies or storage. You get one global, pek (the older name hesper still works).

CallWhat it does
pek.render(ui => tree)Draw the screen. Runs again after taps and requestRender().
pek.requestRender()Redraw after your own async work.
pek.fetchText(url) / fetchJSON(url)HTTPS GET of an allowed host (1 MB, 8 s, no redirects). Needs network.
pek.storage.get / set / removePrivate store. Needs storage.
pek.readData(name) / readJSON(name)Read data/<name> written by the backend. Needs storage.
pek.readBundled(name)Read a JSON file shipped inside your own zip (playlists/<name>, 1 MB). No permission needed.
ui.card / listRow / button / text / heading / column / rowBasic building blocks. Text only, no HTML. ui.button(label, fn, {primary, selected}).
ui.episodeRow({...})One episode: 16:9 still, title, a line of facts and a description. Check if (ui.episodeRow) for older versions.
ui.posterCard(title, sub, posterUrl, fn, {badge})A poster tile like the library grid.
ui.grid(children, {minColWidth, scroll})Responsive poster grid, or one sideways-scrolling row.
ui.tabs / textInput / spinner / toggleTab strip, text box, loading wheel, on/off switch.
ui.video({id, autoplay, muted, title})A YouTube player pinned to the top of the screen. Needs www.youtube-nocookie.com in network.
{autofocus: 'key'}Where the remote's highlight lands when a screen first shows.
pek.setBack(fn)Make Back call fn first so a plugin can step out of its own screens. Pass null to let Back close the plugin.
pek.scrollTop()Scroll back to the top after changing page.
pek.render(function (ui) {
  return ui.column([
    ui.heading('Hello'),
    ui.button('Tap me', function () { pek.requestRender(); }, { primary: true })
  ]);
});

Backend (backend.py)

Optional. It must pass an automatic scan and then runs with a limited host API. run() is called once at startup with a 10 second limit.

  • Allowed imports: json re math datetime time collections itertools functools string textwrap html urllib.parse base64 hashlib random statistics decimal fractions typing dataclasses enum copy operator unicodedata, your own .py files in the same folder, and pek_host.
  • Not allowed: eval exec compile open getattr setattr __import__, any attribute starting with _, os sys subprocess socket ctypes and similar, and native or compiled files.
  • import pek_host as h gives h.fetch_text(url), h.fetch_json(url), h.write_json(name, obj), h.read_json(name) and h.library_titles() (needs "library": true). Network and storage obey plugin.json. The old name hesper_host also works.
  • Installed plugins' backends start the next time PEK TV starts. If the scan refuses one, the reason is in PEK TV's log ([PEK Plugin Guard] REFUSED ...).
import pek_host as h

def run():
    titles = h.library_titles()
    h.write_json("library.json", {"count": len(titles)})

Packaging and installing

In the app: Settings → Plugins → Install plugin from .zip, pick the file, read the permissions and confirm. Hold a plugin's row to remove it. The zip needs plugin.json (with a "flutter" entry) and screen.py (plugins that only have a ui.js are no longer accepted), at the top or inside one folder (the folder name becomes the plugin id: lowercase letters, digits, - and _). Installing again with the same id updates the plugin and keeps its data/ folder.

  • Allowed files: .js .json .css .md .txt .png .jpg .jpeg .gif .webp .ico .woff .woff2 .ttf .otf, and .py for the backend.
  • Limits: 200 files, 2 MB per file (200 KB per .py), 8 MB total, no hidden files, no .. in paths.
  • On Android the plugins folder is private to the app, so a .zip install is the way to add plugins. On a computer or Termux you can also drop a folder into plugins/.

Publish on GitHub

  1. Put plugin.json and screen.py at the top of your zip, or inside one folder.
  2. Make a GitHub Release and attach the zip (a .zip asset up to 8 MB). PEK TV installs the latest release.
  3. Keep the folder name or plugin name the same across versions so updates replace the old copy.

More APIs

Torrent streaming

With "torrent": true, a plugin can call pek.torrent.info() and pek.torrent.play({source, title, kind, name, season, episode, year, image}). PEK TV shows its own buffering box and opens the player when enough is downloaded. PEK TV has no torrent search of its own: the plugin supplies the magnet link.

Up next

pek.onNextEpisode(function (req) {
  // req = { phase: 'check' | 'play', showTitle, season, episode }
  // 'check' -> resolve { ok: true, season, episode, name } or { ok: false }
  // 'play'  -> start it with pek.torrent.play(...) and resolve { ok: true }
});

Live streams

With "live": true, pek.live.play({url, title}) opens PEK's player on an http(s) stream (not this device, no credentials in the URL). Add a channel id and PEK TV opens a live session with a now / next banner, a channel switcher and a guide. You register one function with pek.live.onQuery and answer four questions: list, now, guide and url.

Launching and favorites

pek.onLaunch(fn) runs when PEK TV opens your plugin on a title (from Favorites or another plugin). Streaming services and their Android packages are listed in tools/providers.json (run node tools/sync_providers.js after changing it).

The full reference is PLUGINS.md in the repository.

Skins are not plugins

A skin changes colours, corner radius and, optionally, adds CSS. It cannot run code or use the network. Install one from Settings → Skins → Install skin from .zip. A zip is a plugin or a skin, never both: installing the wrong kind fails with a message that says which it is.

{
  "name": "Sunset",
  "author": "You",
  "version": "1.0.0",
  "description": "Warm dusk colours with soft rounded corners.",
  "tokens": { "bg": "#1a0f14", "text": "#fff1e8", "accent": "#ffb347", "radius": "14px" }
}

Allowed files: json css md txt png jpg jpeg gif webp ico woff woff2 ttf otf, up to 60 files, 2 MB each, 6 MB total. The server re-checks every rule. See SKINS.md.
